# Quiz me

1. List what merged since the last quiz (`git log --merges`, closed issues). Pick 5 items that matter most to the README's definition of good.
2. Ask him to describe each change without looking: the mechanism, not the diff. One at a time. Then show the actual code path and say where he was right or wrong.
3. End with the three things he should be able to say in 30 seconds to a marker. Log the gaps as `/learn capture` candidates.
